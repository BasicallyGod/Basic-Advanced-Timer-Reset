# BAT design

Start with the [design specification](BAT-design-specification.md), the authority for current product intent. It distinguishes confirmed requirements, proposals and open decisions.

The [foundation review](BAT-foundation-review.md) records source provenance, reuse candidates and the native feasibility gate. The [decision log](bat-design-decisions.json) preserves discussion history; it does not override the specification. The [original brief](references/BAT-reset-design-brief-original.md) is preserved unchanged.

Update the requirement, open decision and revision history together when direction changes. Record test evidence separately from intent.
